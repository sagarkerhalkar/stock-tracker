    Alerts

    You get a message the moment a product becomes available, goes out of stock, or comes back in stock. Turn on the apps you use, then press Send test to confirm it reaches you.

    Faster checks mean faster alerts, but checking a site too often can get you temporarily blocked. 2 minutes for out-of-stock products is a good balance.

    Open from phone or the internet (Cloudflare Tunnel)

    On this PC you never need a password. From any other device – your phone, another PC, or a Cloudflare Tunnel link – a password is required.

    1. Set a password
    2. Phone / other PC on the same Wi-Fi

      The first time, Windows may ask "Allow Python on private networks?" – click Allow.

    3. From anywhere – Cloudflare Tunnel (works with or without step 2)

      Quick test link, no account: double-click 9_CLOUDFLARE_TUNNEL.bat in your Restock Watch folder. It installs cloudflared if needed and shows a link like https://xxxx.trycloudflare.com (a new link each time).

      Permanent address on your own domain: Cloudflare dashboard → Zero Trust → Networks → Tunnels → Create a tunnel (Cloudflared) → choose Windows and run the install command it shows in an Administrator Command Prompt → add a public hostname (e.g. stock.yourdomain.com) with Service HTTP and URL localhost:8787.
